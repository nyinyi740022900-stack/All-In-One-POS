အဆင့်ဆင့် အသုံးပြုနည်း

၁

ကုန်ပစ္စည်းစာရင်း ကြည့်ရှုပါ

ကုန်ပစ္စည်းတစ်ခုစီကို ပုံ၊ အမည်၊ ဈေးနှုန်း၊ လက်ကျန်အရေအတွက် Pill နဲ့ ပြပေးပါတယ် — လက်ကျန်နည်းရင် "လက်ကျန်နည်းနေသည်" Banner ပေါ်လာပြီး Pill ရောင်လည်း ပြောင်းသွားပါတယ်။ Search field နဲ့ ရှာနိုင်ပြီး၊ Category chip တွေနဲ့ စစ်ထုတ်ကြည့်နိုင်ပါတယ် (Sell screen ရဲ့ chip အတိုင်း တူညီပါတယ်)။

  • Cashier role က ကြည့်ရှုနိုင်ပေမယ့် ပြင်ဆင်ခွင့် မရှိပါ (Owner/Manager သာ ပြင်နိုင်)
  • Stock tracking ကို လုံးဝပိတ်ထားလည်း ရနိုင်သည် (ထိန်းချုပ်လိုသော ဆိုင်များအတွက်)
၂

ကုန်ပစ္စည်းအသစ် ထည့်ပါ (သို့) ပြင်ပါ

"+" ခလုတ်ကို နှိပ်ပြီး ပုံတင်ပါ၊ အမည်၊ Category ရွေးပါ၊ ဈေးနှုန်း (ရောင်းဈေး/ဝယ်ဈေး/ လက်ကား/VIP) ထည့်ပါ၊ လက်ကျန်အရေအတွက်နဲ့ Reorder level ထည့်ပါ။ Barcode ကို Camera icon နှိပ်ပြီး Scan လုပ်နိုင်သလို၊ USB/Bluetooth Scanner တွဲထားရင် အလိုအလျောက် field ထဲ ဝင်သွားပါတယ်။

  • Wholesale/VIP ဈေးနှုန်း ထည့်ထားရင် Sell screen မှာ ဖောက်သည် tier အလိုက် အလိုအလျောက် သုံးပေးသည်
၃

လက်ကျန် ပြင်ဆင်ပါ

Row ပေါ်က Stock Pill ကို (သို့) "…" menu ထဲက "လက်ကျန် ပြင်ဆင်ရန်" ကို နှိပ်ပါ — ပစ္စည်းအသစ်ထည့် (Restock, အမြဲ တိုးတယ်) နဲ့ ချိန်ညှိရန် (Adjust — ပျက်စီး/ပျောက်ဆုံး/ရေတွက်မှန်ကန်ရေး/အခြား အကြောင်းပြချက်ဖြင့် +/− ပြင်ဆင်ခြင်း) နှစ်မျိုး ရွေးနိုင်ပါတယ်။ ပြင်ဆင်တိုင်း Stock History ထဲမှာ မှတ်တမ်းအပြည့် ကျန်ရစ်ပါတယ်။

သိထားသင့်တဲ့ Tips

Barcode Label ပရင့်ထုတ်ခြင်း — ကုန်ပစ္စည်းတစ်ခုစီအတွက် Label (အမည်+ဈေး+Barcode) ကို dedicated Label Printer (သို့) Receipt Printer strip ပေါ်တွင် ထုတ်နိုင်ပါသည်။

CSV Export — Inventory List ကို CSV file အဖြစ် Export လုပ်နိုင်သည် (Premium)။ Import လုပ်ရန်မူ Backup ဖြင့်သာ ဖြစ်နိုင်သည်။

Category Filter — Inventory နဲ့ Sell screen နှစ်ခုစလုံးက Category chip တူတူသုံးလို့ ကုန်ပစ္စည်း စာရင်း အမြဲညီညွတ်နေသည်။

Stock History — ကုန်ပစ္စည်းတစ်ခုစီရဲ့ လက်ကျန်ပြောင်းလဲမှု မှတ်တမ်းအားလုံးကို audit trail အဖြစ် ကြည့်ရှုနိုင်သည်။
