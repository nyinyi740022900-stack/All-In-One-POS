ဆက်တင် → ပရင်တာ ဆက်တင် သို့ဝင်ပါ။ စက္ကူအရွယ် မှာ 58mm၊ 80mm၊ 80mm (ကျဉ်းသော ပုံနှိပ်) သုံးမျိုးကြားက ရွေးနိုင်ပြီး — စာလုံးတွေ ကျော်ထွက်နေ (သို့) ဖြတ်သွားနေရင် Epson TM-T88 မျိုး Printer တွေအတွက် ကျဉ်းသောအရွယ်ကို သုံးဖို့ Hint စာသားက သတိပေးထားသည်။ Document paper size (A4/A5) ကတော့ သီးခြား Setting ဖြစ်ပြီး AirPrint (သို့) Computer ကနေ ပရင့်ထုတ်မယ့် PDF အတွက်သာဖြစ်သည် — Thermal Printer အတွက် လုံးဝ မဟုတ်ပါ။ ဒီစက်က ပရင်တာနဲ့ ဘယ်လို ချိတ်မလဲ မှာ Bluetooth/Wi-Fi/USB ရွေးနိုင်သည်။

သိထားသင့်တဲ့ Tips

Test Print — Pair ပြီးတိုင်း "Test Print" ခလုတ်ဖြင့် မြန်မာစာနမူနာ ပြေစာတစ်စောင် ပရင့်ထုတ်ပြီး ချိတ်ဆက်မှု စစ်ဆေးနိုင်သည်။

Auto-print — ရောင်းချမှုတိုင်း ငွေရှင်းပြီးတာနှင့် ပရင်တာက နောက်ကွယ်မှာ အလိုအလျောက် ပရင့်ထုတ်ပေးသည် — Printer offline ဖြစ်နေလည်း ရောင်းချမှုကို မဆွဲမနှေးစေပါ။

Myanmar Raster ပုံနှိပ်စနစ် — Font မထည့်ရသေးသော Printer များအတွက်တောင် မြန်မာစာကို ပုံအဖြစ် ပြောင်းပြီး ပရင့်ထုတ်ပေးနိုင်သည်။

Label Printing — သီးခြား "Label Printer" Setting Screen (ကိုယ်ပိုင် စက္ကူအရွယ်: 30×20 / 40×30 / 50×30 / 50×40 / 60×40 / 100×50 mm) ဖြင့် Inventory ထဲက ကုန်ပစ္စည်းတစ်ခုစီအတွက် Label (အမည်+ဈေး+Barcode) ကို ထုတ်နိုင်သည်။
