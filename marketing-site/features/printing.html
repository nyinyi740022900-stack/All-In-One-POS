ပရင်တာ ရှာဖွေ ချိတ်ဆက်ပါ

ဆက်တင် → ပရင်တာ ဆက်တင် သို့ဝင်ပါ။ ချိတ်ဆက်မှုအမျိုးအစား (Bluetooth/Wi-Fi/USB) ကို segmented control ဖြင့် ရွေးပါ — Bluetooth ဆိုရင် Pair လုပ်ထားပြီးသား စက်များကို Scan လုပ်ပြီးပြပေးမည်၊ Wi-Fi ဆိုရင် Network ပေါ်ကရှာ (သို့) IP:port ကိုယ်တိုင် ရိုက်ထည့် နိုင်သည်။ ပထမဆုံးအကြိမ် Pair လုပ်ချိန် စက္ကူအရွယ် (58mm/80mm) ကို Printer အမည်ကို ကြည့်ပြီး အလိုအလျောက် အကြံပြုပေးသည်။

  • ပြေစာစက္ကူအရွယ် (58/80mm) နှင့် PDF Document အတွက် A4/A5 setting ခွဲထားသည်

သိထားသင့်တဲ့ Tips

Test Print — Pair ပြီးတိုင်း "Test Print" ခလုတ်ဖြင့် မြန်မာစာနမူနာ ပြေစာတစ်စောင် ပရင့်ထုတ်ပြီး ချိတ်ဆက်မှု စစ်ဆေးနိုင်သည်။

Auto-print — ရောင်းချမှုတိုင်း ငွေရှင်းပြီးတာနှင့် ပရင်တာက နောက်ကွယ်မှာ အလိုအလျောက် ပရင့်ထုတ်ပေးသည် — Printer offline ဖြစ်နေလည်း ရောင်းချမှုကို မဆွဲမနှေးစေပါ။

Myanmar Raster ပုံနှိပ်စနစ် — Font မထည့်ရသေးသော Printer များအတွက်တောင် မြန်မာစာကို ပုံအဖြစ် ပြောင်းပြီး ပရင့်ထုတ်ပေးနိုင်သည်။

Label Printing — Inventory ထဲက ကုန်ပစ္စည်းတစ်ခုစီအတွက် Label (အမည်+ဈေး+Barcode) ကို dedicated Label Printer (သို့) Receipt Printer strip ပေါ်တွင် ထုတ်နိုင်သည်။
