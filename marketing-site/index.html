ဝန်ဆောင်မှုများ

ဆိုင်စီမံခန့်ခွဲမှု လိုအပ်သမျှ
တစ်နေရာတည်းမှာ

လက်ငင်းရောင်းချခြင်းမှသည် နှစ်ချုပ်စာရင်း ထုတ်ခြင်းအထိ — code မတတ်လည်း လွယ်ကူစွာ အသုံးပြုနိုင်အောင် ဒီဇိုင်းလုပ်ထားပါတယ်။

၀၁

အမြန်ရောင်းချခြင်း

ကုန်ပစ္စည်း Grid ကနေ Cart ထဲထည့်၊ ငွေရှင်း — Cash, KBZPay, WavePay, AYAPay, CBPay အားလုံးလက်ခံ။ ပြေစာနံပါတ် အလိုအလျောက်ရိုက်ပေးတယ်။

၀၂

Bluetooth ပရင့်ထုတ်ခြင်း

58/80mm Thermal Printer အားလုံးနှင့် တွဲသုံးလို့ရ — Font မရှိတဲ့ Printer တွေအတွက်တောင် မြန်မာစာ Raster ပုံနှိပ်စနစ်ပါ ထည့်ပေးထားပါတယ်။

၀၃

Cloud Sync & Analytics

Offline မှာ အရောင်းဆက်လုပ်ပြီး အင်တာနက်ရသည်နှင့် အလိုအလျောက် Sync ဖြစ်သွားပါတယ် — ဆိုင်ခွဲများအားလုံးအတွက် စာရင်းချုပ်၊ ဝင်ငွေ၊ အမြတ်အစွန်းကို တစ်နေရာတည်းမှာ တွေ့နိုင်ပါတယ်။

Inventory စီမံခန့်ခွဲမှု

Category, Barcode, Stock အနည်းဆုံးအဆင့် သတိပေးချက်များ — ကုန်ပစ္စည်း ကုန်ခန်းကို အချိန်နှင့်တပြေးညီ စောင့်ကြည့်နိုင်ပါတယ်။

အစီရင်ခံစာ

နေ့စဉ်ဝင်ငွေ၊ အမြတ်အစွန်း၊ ရောင်းရဆုံးကုန်ပစ္စည်း စသည်တို့ကို Chart နှင့်အတူ Offline အခြေအနေမှာပင် ကြည့်ရှုနိုင်ပါတယ်။

Credit Book & Expenses

ဖောက်သည်ချေးငွေစာရင်း၊ ဆိုင်ကုန်ကျစရိတ် (Expenses) များကို တစ်နေရာတည်းမှာ မှတ်တမ်းတင် စီမံနိုင်ပါတယ်။

အသုံးပြုပုံ

မိနစ်အနည်းငယ်အတွင်း
စတင်နိုင်ပါပြီ

Setup ရှုပ်ထွေးမှုမရှိပါ — Download ချပြီး လိုက်လုပ်ရုံပါပဲ။

၁

App ကို ဒေါင်းလုပ်ဆွဲပါ

ဖုန်း (Android/iOS) သို့မဟုတ် Windows Computer အတွက် အောက်က Download ကဏ္ဍမှာ ဆွဲယူပါ။

၂

ဆိုင်အချက်အလက် ထည့်ပါ

ဆိုင်နာမည်၊ ကုန်ပစ္စည်းစာရင်း ထည့်ပါ — Excel ကနေ Import လုပ်လည်း ရပါတယ်။ 2 လ အခမဲ့ စမ်းသပ်ကာလ ရရှိပါမယ်။

၃

ရောင်းချစတင်ပါ

အင်တာနက်ရှိလည်း မရှိလည်း ဆက်လက်ရောင်းချနိုင်ပါတယ် — ပြေစာကို ပရင့်ထုတ် (သို့) ဓာတ်ပုံအဖြစ် ပို့ပေးနိုင်ပါတယ်။

၄

အစီရင်ခံစာ ကြည့်ရှုပါ

ဝင်ငွေ၊ အမြတ်၊ ကုန်ပစ္စည်း အခြေအနေများကို Analytics စာမျက်နှာမှာ တစ်ချက်ကြည့်ရုံနဲ့ သိနိုင်ပါတယ်။

ဒေါင်းလုပ်

ယနေ့ပင် စတင်လိုက်ပါ

Device မည်သည့်ပလက်ဖောင်းပေါ်တွင်မဆို All In One POS ကို အသုံးပြုနိုင်ပါတယ်။

Windows

Computer / Laptop အတွက် — Zip ဖိုင်ကို Extract လုပ်ပြီး AllInOnePOS.exe ကို ဖွင့်ရုံပါပဲ။

Windows အတွက် ဒေါင်းလုပ်ဆွဲမည် .zip ဖိုင် • နောက်ဆုံးထုတ်ဗားရှင်း အလိုအလျောက် အသစ်ပြောင်းပေးသည်

iOS

iPhone / iPad အတွက် App Store ထုတ်ဝေရန် ပြင်ဆင်နေပါသည်။

မကြာမီ လာမည် အခုအချိန်တွင် Support ကို ဆက်သွယ်ပါက သီးသန့် Access ရနိုင်ပါသည်

Android

Android ဖုန်း / Tablet အတွက် Play Store ထုတ်ဝေရန် ပြင်ဆင်နေပါသည်။
