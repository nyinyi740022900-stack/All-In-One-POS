ဝန်ဆောင်မှုများ

ဆိုင်စီမံခန့်ခွဲမှု လိုအပ်သမျှ
တစ်နေရာတည်းမှာ

လက်ငင်းရောင်းချခြင်းမှသည် နှစ်ချုပ်စာရင်း ထုတ်ခြင်းအထိ — code မတတ်လည်း လွယ်ကူစွာ အသုံးပြုနိုင်အောင် ဒီဇိုင်းလုပ်ထားပါတယ်။

၀၁

အမြန်ရောင်းချခြင်း

ကုန်ပစ္စည်း Grid ကနေ Cart ထဲထည့်၊ ငွေရှင်း — Cash, KBZPay, WavePay, AYAPay, CBPay အားလုံးလက်ခံ။ ပြေစာနံပါတ် အလိုအလျောက်ရိုက်ပေးတယ်။

၀၂

Bluetooth ပရင့်ထုတ်ခြင်း

58/80mm Thermal Printer အားလုံးနှင့် တွဲသုံးလို့ရ — Font မရှိတဲ့ Printer တွေအတွက်တောင် မြန်မာစာ Raster ပုံနှိပ်စနစ်ပါ ထည့်ပေးထားပါတယ်။

၀၃

Cloud Sync & Analytics

Offline မှာ အရောင်းဆက်လုပ်ပြီး အင်တာနက်ရသည်နှင့် အလိုအလျောက် Sync ဖြစ်သွားပါတယ် — ဆိုင်ခွဲများအားလုံးအတွက် စာရင်းချုပ်၊ ဝင်ငွေ၊ အမြတ်အစွန်းကို တစ်နေရာတည်းမှာ တွေ့နိုင်ပါတယ်။

Inventory စီမံခန့်ခွဲမှု

Category, Barcode, Stock အနည်းဆုံးအဆင့် သတိပေးချက်များ — ကုန်ပစ္စည်း ကုန်ခန်းကို အချိန်နှင့်တပြေးညီ စောင့်ကြည့်နိုင်ပါတယ်။

အစီရင်ခံစာ

နေ့စဉ်ဝင်ငွေ၊ အမြတ်အစွန်း၊ ရောင်းရဆုံးကုန်ပစ္စည်း စသည်တို့ကို Chart နှင့်အတူ Offline အခြေအနေမှာပင် ကြည့်ရှုနိုင်ပါတယ်။
